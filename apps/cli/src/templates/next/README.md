# Next.js app

Opinionated standalone Next.js App Router starter generated by Arche.

## What's included

- App Router with `error`, `loading`, and `not-found` boundaries
- Env validation via `@t3-oss/env-nextjs` (`env.ts`)
- SEO metadata baseline in `app/layout.tsx`
- Sample Route Handler at `GET /api/health`
- Design tokens in `app/styles.css` and a small `components/` example

## Commands

```bash
bun install
bun dev
bun run lint
bun run check-types
bun run build
```

## Where to go next

- Add routes under `app/`
- Extend `env.ts` when you introduce new public configuration
- Wire a backend or data layer when your product needs one — this template stays backend-agnostic
